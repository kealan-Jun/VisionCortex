# RTX 4090 部署

[本地启动](../../docs/guides/local-development.zh-CN.md) · [发布与部署](../../docs/RELEASE-POLICY.md)

本目录提供目标硬件的部署资料。首次克隆使用本地开发配置检查启动；生产模型运行前
由部署方提供固定源码、匹配的依赖锁、模型与目标机生成的引擎，以及私有站点配置。

源代码不包含模型、引擎、真实输入或运行数据。生产输入索引、设备地址、NAS 根、
本地缓存和输出位置取自经过验证的站点配置，不沿用其他部署的路径或成绩。

现有脚本执行前核对配置、解释器、模型身份、容量、服务归属及活动任务。
缺少生产参数时停止；安装、GPU 运行、存储访问和服务升级分别按部署任务执行。
合成媒体或健康接口通过不代表真实视频质量。

正式交付使用[验收单](../../docs/VisionCortex-交付验收单模板.md)记录当前机器的完整证据。
