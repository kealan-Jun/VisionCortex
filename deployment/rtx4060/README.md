# Windows RTX 4060 节点

[文档导航](../../docs/README.md) · [本地启动](../../docs/guides/local-development.zh-CN.md) · [交付验收](../../docs/VisionCortex-交付验收单模板.md)

首次克隆先使用项目的本地启动入口检查环境和网页。生产执行需要部署方提供
固定源码提交、经过验证的依赖与模型，以及不进入 Git 的站点配置和输入清单。

## 安装与运行

在现有仓库的实际目录操作，不假定盘符或复制另一份源码。
模型运行环境、FFmpeg、CUDA 和 TensorRT 必须适配目标机；引擎由目标 GPU 生成，
不得把其他机器的引擎作为本机通过证据。安装或引擎准备按具体部署任务执行。

本目录的节点脚本用于已配置的部署环境。执行前检查脚本采用的配置、存储根、
模型路径和服务身份；存在未设置的生产参数时停止，不沿用其他站点的默认值。
需要固定基准的站点应私有保存其任务书、实验身份、设备绑定和回传记录。

用户提交与结果查看使用 Web 页面或公开 API。任务提交后保存任务身份、状态地址和
提交回执；客户端退出不表示流水线完成。活动任务期间不得停止或重启所属服务，
提交成功后不得重复创建同一任务。

## 存储与证据

源码和 Python 环境使用实际本地安装目录；模型、活动账本和缓存使用已验证的本地路径。
原片、归档和 staging 由私有站点配置及提交回执确定，禁止替换为另一站点的路径。
分片原生输入直接引用原始媒体与时钟索引，不创建每路长视频的重复副本。
派生产物通过适用的身份与质量检查后才发布；历史输入和回执保留自身身份。

缓存绑定递归源码、有效配置、模型与输入。新身份可能要求重新计算，
不能把旧缓存或旧性能数字当作本次运行证据。
密钥通过本机安全设置提供，不进入代码、配置模板、日志或 Git。

本地结构检查、实际模型调用、真实视频质量、浏览器交付和正式发布资格分别验收。
