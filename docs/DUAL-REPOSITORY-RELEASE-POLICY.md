# VisionCortex 双仓同步与生产发布

2026-09-15 用户确认的两个平等同步目标持续有效：

- `https://github.com/kealan-Jun/VisionCortex.git`
- `https://github.com/RealityLoopAI/VisionCortex.git`

`development`、`origin` 只是历史远端别名，没有开发仓与稳定仓之分。
同步前核对 URL、默认分支、当前分支、HEAD、上游、工作树和双方远端 SHA，
获取并保留远端新提交，先解决分歧。仅按明确路径暂存，经评审后将同一个提交
推送到两端 `main` 和明确共享的工作分支，再查询两侧目标 SHA 确认相同。
不强推、不使用 `--mirror`，不删除其他分支、标签或独有历史。

GitHub Actions 保持仅手动入口。常规同步不启动或等待 CI，也不把同步结果
当作服务上线、模型运行或稳定发布证明。构建、部署、回滚与验收遵守
[发布与部署规则](RELEASE-POLICY.md)，分别保留实际证据。

生产从经验证的固定 SHA 构建不可变源码，复用核验过的环境、私有配置和模型。
切换前备份队列、配置、服务覆盖及必要回执，有序交接在途工作；
回退不覆盖数据库、不删除现场原始数据或历史结果。
RTX 4060 继续是冻结执行节点，未经另行授权不得用于开发、改码、调参或测试。

本路径恢复为当前政策入口，兼容仍引用其名称的项目指导与历史调用方。
