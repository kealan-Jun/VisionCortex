# VisionCortex 多模态模型配额与 TPS 提升申请

## 申请结论

请火山引擎方舟团队针对 `doubao-seed-2-1-pro-260628` 提供独立的输入/输出 Token 吞吐和并发配额，并协助确认自定义 Endpoint ID。生产建议配额为：稳定并发 12、突发并发 16、输入 TPS 不低于 5,000、输出 TPS 不低于 1,000、RPM 不低于 60，关键素材请求 P95 目标低于 20 秒。

## 技术标识

- 厂商：火山引擎方舟
- 模型 ID：`doubao-seed-2-1-pro-260628`
- Responses API：`https://ark.cn-beijing.volces.com/api/v3/responses`
- 自定义 Endpoint ID：当前代码未配置，需要由方舟控制台/厂商补充
- API Key：不进入文档和仓库，由运行环境变量 `ARK_API_KEY` 提供

## 六路正式归档实测

- 85 次成功调用：实验片段 5 次，关键素材 80 次。
- 输入 323,410 tokens；输出 53,197 tokens；总计 376,607 tokens。
- 实验片段调用 31.81–61.12 秒，中位数 43.76 秒。
- 关键素材调用 12.59–33.09 秒，中位数 18.15 秒，P95 约 24.30 秒。
- 关键素材阶段约 22 RPM、输入 1,154 TPS、输出 189 TPS。
- 85 次成功调用共发生 86 次尝试，即发生 1 次重试。

## 风险边界

- 本申请只包含模型标识、聚合性能与建议配额，不包含 API Key。
- `自定义 Endpoint ID` 在确认前保持未配置状态，不以模型 ID 猜测 Endpoint。
- 实测来自一次正式六路归档；后续应按 `model + endpoint + prompt_version + input_hash` 留存调用收据。
- 提高额度后仍由客户端使用有界并发、指数退避和幂等缓存，避免形成重试风暴。
