# 模型切换时保留历史完成结果

`device_day.completed_execution_bindings` 引用本地清单及其 SHA-256。
清单只保存来源身份、原执行配置的非秘密部分、精确阶段键、完成回执摘要和
队列修订；不保存 API 密钥，不把原厂商输出标为新厂商输出。

运行器用当前完整输入重算原配置的阶段键，只有与清单一致时才复用原完成结果。
产物仍需通过正常内容验证。缺失、损坏或被替换的已绑定回执不能回落为“用新
厂商执行、写旧键”。来源、上下文或上游结果变化后，重新按当前有效配置判断。
新的、原本未完成的多模态任务使用已验证的新厂商；语音连接可单独固定在原
ASR 厂商，避免多模态全局设置改变转写连接。

切换前已与原配置不匹配的完成记录必须单列，不能伪造兼容别名。部署清单可将
这些记录标为待核验，保留其原队列完成记录，但不将失效回执作为有效前置证据，
也不自动对同一批历史输入发起新的付费调用。待核验范围同时绑定来源、原队列
修订及本次实际观察到的输入配方。未来再次切换厂商或改变请求参数，应重新
审核清单，不能假定旧清单覆盖另一轮切换。

清单应由部署现场读取原配置、阶段回执和队列生成，不属于仓库数据。
本地配置中仅保存清单路径与摘要。确定性测试证明复用与拒绝规则；实际模型
调用、真实媒体质量和持续生产吞吐需要各自的运行证据。
