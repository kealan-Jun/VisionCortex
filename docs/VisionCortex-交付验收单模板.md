## 2. 证据结论规则

| 结论 | 使用条件 |
| --- | --- |
| `PROVEN` | 当前 SHA、当前生产配置和本次真实输入有直接运行回执或验收文件 |
| `PARTIAL_EVIDENCE` | 只有部分门禁通过，或引用的是历史运行、合成输入、其他机器/SHA |
| `NOT_PROVEN` | 尚未执行、证据不可读取或缺少必要回执 |

合成六路验收、网页可打开、HTTP 200 或单元测试通过，均不能单独证明真实生产质量。
