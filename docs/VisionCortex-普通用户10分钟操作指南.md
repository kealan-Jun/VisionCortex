# VisionCortex 普通用户 10 分钟操作指南

从打开工作台到找到分析结果，按下面的顺序操作。服务器安装和模型准备由管理员完成；第一次克隆源码时，请先按[本地启动说明](guides/local-development.zh-CN.md)安装和启动。

## 1. 打开工作台，确认当前环境

使用管理员提供的服务地址和账户登录，或打开本地启动器输出的地址。首页标题为“实验运行概览”，可以点击“新建实验”，也可以通过“选择视频”进入创建流程。

全新本地环境没有实验档案是正常状态。默认 `demo` 配置用于浏览页面和检查安装：服务状态页可能显示本地存储目录可用、视频处理待配置，以及真实分析环境未配置。它不能证明模型已经执行，也不能直接用于正式视频验收。

正式提交前，在“服务状态”确认：

- 存储位置符合本次任务要求；NAS 输入需要已验证的站点挂载和索引。
- 视频处理环境与所选模型已准备，当前没有阻断说明。
- 需要智能理解时，所选 AI 服务已配置并通过实际连接验证。

页面可打开、目录可用和服务连接通过分别证明不同步骤；真实视频质量需要本次分析回执和人工核对。出现“待配置”时，先联系管理员完成准备，不重复提交任务。

## 2. 新建实验，选择正确的输入方式

“新建实验”按“导入视频 → 命名实验 → 确认分析方式 → 开始处理”组织流程。

如果数据已经进入站点的采集索引，使用“选择采集批次”。核对日期、批次、机位角色与分片数；只有状态允许分析的批次才提交。该入口直接读取已登记的原片，不需要再次上传。

索引外的数据使用“选择文件”或“选择文件夹”：

1. 一次选择同一次实验的全部视频，以及可选的时间戳 CSV。
2. 为每路视频填写唯一机位 ID，并选择实际第一人称或第三人称视角。
3. 至少包含一路第一人称和一路第三人称；CSV 分别映射到对应机位，没有则留空。
4. 命名实验并核对文件数、总大小、输入方式、分析方式和容量检查结果。
5. 阅读最终确认区后开始处理。采集索引输入应显示“源视频复制 0 字节”；上传输入按实际字节预留空间。

上传中断后保留当前任务，重新选择完全相同的文件继续。文件名、大小、修改时间或断点内容变化时，不应拼接到旧上传会话。

## 3. 记录任务信息，查看进度

保存任务 ID、归档名称和提交时间。在“任务进度”查看：

| 状态 | 含义与下一步 |
| --- | --- |
| `queued` | 等待资源；不要重复提交 |
| `running` | 正在处理；观察当前环节和状态更新时间 |
| `completed` | 流程完成，继续核对结果与验收回执 |
| `partial`、`failed`、`interrupted` | 保留已完成成果；记录错误或缺口，由管理员决定恢复范围 |

状态同步失败时，以页面的同步提示为准，不能凭旧进度判断任务已停止。恢复任务前核对原任务身份、输入、配置和已保存回执。

## 4. 打开实验记录，逐项验收

从“实验记录”打开对应实验，按结果页导航检查：

| 页面 | 检查什么 |
| --- | --- |
| **视频与操作步骤** | 实验边界、第一/第三人称和对齐视频可播放；同一动作时间一致 |
| **录音与转写** | 本次录音来源、实际转写和缺失说明；无录音不使用其他日期代替 |
| **关键素材** | 动作、参与对象、证据时间和视角；区分画面确认、模型提示与证据不足 |
| **日报与报告** | 报告与视频证据一致，保留未知、遮挡、冲突和阶段性结果说明 |
| **分析记录** | 实际执行/复用次数、阶段耗时、质量回执和供应商实际返回的用量 |

“关键素材库”和“实验室日报”提供跨档案查看入口。空列表表示尚无已发布成果，不能当作“没有实验活动”或“质量通过”。

## 5. 登记交付结论

只有对应本次输入、当前版本和实际运行的证据可以支撑验收：

- [ ] 任务最终状态和完整性说明已核对。
- [ ] 视频、关键素材、报告与文件级验收回执相互一致。
- [ ] 未知、遮挡、冲突没有被改写为确定事实。
- [ ] 需要云端模型时，实际调用回执与用量可追溯；未知用量不记为零。
- [ ] 任务 ID、归档身份、问题和人工抽查结果已登记。

使用[交付验收单](VisionCortex-交付验收单模板.md)记录 `PROVEN`、`PARTIAL_EVIDENCE` 或 `NOT_PROVEN`。涉及部署、故障或文件检查时，继续阅读[端到端交付手册](VisionCortex-端到端视频分析交付手册.md)。不要把账户密码、密钥或现场设备信息写入公开工单与仓库。
