## 冲突解决与保留边界

- 离线分析通过同一个 EvidencePipeline/StageRunner 执行；阶段恢复使用纯 JSON、
  输入/模型/配置/代码身份和产物校验，失效阶段及依赖重算。任务取消继续向上抛出。
- STT 在对齐后异步启动，粗扫、精扫和候选处理继续运行；进入语义理解前收取结果。
  可选录音失败保留原件和回执，视觉继续；要求录音的配置仍约束完整发布。
- 保留当前统一资源调度、GPU 调用边界、Qwen 适配、持久任务防重及重试逻辑。
  训练运行时旧入口仅转调现有实现，不复制另一套训练代码。
- 第一/第三人称关联继续依赖证据；默认不把未验证配对标成已确认。
  连续实验尾部、每步引用事件及可观察结果有独立校验。
- FFmpeg 6+ 的编码前原生 PTS 统计与现有原生帧缓存、采样时间和覆盖缺口检查结合；
  缺失或歧义身份不会被标成已验证。
- 网页增加阶段成果/恢复/跟随入口，同时保留 NAS 日期页、队列、知识检索、异步刷新
  防过期覆盖及播放/编辑保护。阶段成功与正式发布状态分开显示。
- 并发初始化输入可用性 SQLite 时，仅对 SQLITE_BUSY 有界重试，其他错误正常返回。
- NAS 设备日 MetaVideo、ProcessedClips、MultimodalUnderstanding、LaboratoryDailyReport、
  Comment 五目录及其冻结语义不变。新增阶段清单命名 StageInventory.json；旧离线档案
  内部路径继续兼容。没有执行原片删除/替换，没有混用日期录音。
- 派生检索索引可重建；液体状态缺失保持未知。只读验收结果使用 PARTIAL_EVIDENCE /
  NOT_PROVEN，并保留尚缺当前部署、真实视频质量与浏览器交付验收的说明。
