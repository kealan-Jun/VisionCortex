# 交付手册截图说明

这些截图于 2026-09-03 从本机 VisionCortex Web 界面截取，用于交付手册中的页面
定位和按钮识别。

截图对应的是本地合成验收归档 `VC-LOCAL-SIX-VIEW-ACCEPTANCE`。该环境为
`local_development`，NAS 不可用、MLLM 未启用，输入为合成六路短视频，模型 Token
为 0。因此截图只证明界面可访问和结果结构可展示，不证明生产 NAS、真实模型、真实
视频质量、3090 Ti 性能或当前版本正式验收通过。

正式验收必须使用生产配置和本次真实运行回执，并填写
[`VisionCortex 交付验收单模板`](../../VisionCortex-交付验收单模板.md)。
