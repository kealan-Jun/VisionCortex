# 项目标注、人称分类与候选训练规范

本规范用于用户授权的项目标注和内部候选模型实验，补充
`YOLO-Box-Ground-Truth-and-Annotation-Contract.zh-CN.md`。
显示名称为“项目标注”。保留标注方法和源文件摘要，不虚构人工标注员、
双人复核或独立真值；模型草稿始终是 `pseudo_labels_not_ground_truth`。
内部项目标注比较不能替代正式独立评测或生产晋升门禁。

## 人称与机位

- 分别建立 `first_person`、`third_person` 数据集、训练运行及候选权重。
  一个机位只使用对应人称的模型。同人称的多个机位可以共享权重，
  各自保留独立帧、框、轨迹、相机编号和时间戳。
- 人称依据采集清单、相机安装身份及原序列核定。文件名是线索；
  不把近景自动当第一人称，不把没有手的画面自动当第三人称。
- 缺少来源依据时记录项目视觉分类及依据；无法判断的记为 `unknown`，
  暂不进入人称训练集。单张图片不能证明相机实际安装位置。
- 原视频/实验批次必须整体进入一个分区，跨机位也不能拆开。
  同操作员、近重复图片的跨分区问题仍需核对，不能仅按图片随机划分。
- 原模型使用过的训练图片即使重新标注、重新分区，也不是原模型的独立测试集。
- 后续跨机位核验可关联来源明确的观测；同类别、时间共现或两个模型一致，
  均不能单独确认同一实体或物理动作。禁止先混合不同机位的检测框再做跟踪。

## 实例边界

- 一件可辨认实物一个框，逐件补漏并移除同一物体的重复框。
  移液枪架与每支移液枪、试管架与每根试管分别标注。
- 可见管盖、瓶盖、单支枪头单独标注，并记录与主体的部件关系。
  主体有盖时仍是一件主体；只露出盖、完全看不见管身时，不凭盖补画管身。
- 框包住可见部分；透明架后的清晰管身仍然可见。严重遮挡时记录可见性，
  不推测被遮住的轮廓，也不根据架子的孔数推测装了多少支。
- 反射和折射不增加物理实例数量。空孔不是试管，枪头盒不是单支枪头。
- 斜置长条器材的轴对齐矩形可以自然重叠并包含邻物的一部分。按每支可见枪身、枪杆和端部建立对应；不能仅凭矩形重叠判为重复或合并实物。模型框的IoU匹配也不能独立证明同一物理实例。
- `hand` 与 `gloved_hand` 互斥，框以手掌和手指的可见范围为依据。
  裸露手腕、桌布、未穿戴手套和屏幕里的手不能分别冒充另一只实体手。
- 同一人同一件实验服仅因两个袖段分离可见，不计为两件；以明确属于同一件衣服的
  可见部分总体范围建一个框，记录严重遮挡。不同人的服装不合并；不能判断归属的区域待核对。
- 瓶盖完全在画面外或被遮住时，不按邻帧的盖色沿用蓝盖类别；只对本帧可辨认的瓶体
  分类。只露盖、完全看不见瓶体时，仅标盖；完全被挡住的实物不按先前位置补框。
- 同一台电子天平的玻璃防风罩与底座计为一个实例；只取本帧可见部件的总体边界，
  不猜被手遮住的底座范围。单张称量纸与其后另一个纸包可分辨时分别标注。
- 透明容器的液体颜色不用于猜测物质身份。带刻度及杯口的烧杯、螺口小样品瓶、
  有可辨认试剂瓶特征的瓶体按统一口径标注；用途不可确定的容器不得强猜试剂类别。
- 保持既有 0–20 类编号。在项目标注本体中追加 `21: pipette_rack`、
  `22: pipette_tip_box`，解决既有类表无法区分架子、盒子和单件的问题。
  这是候选数据本体；未同步训练、评测两个角色前，不改生产模型类表或替换引擎。

## 不确定区域与负样本

- 放大核对密集小目标。看不清的区域明确记为 ignore，并记录原因；
  不自动把没有框的区域当作负样本。
- 普通 YOLO 框训练不认识项目 ignore 字段。导出必须拒绝未经处理的 ignore，
  或生成有完整溯源的、避开这些区域且重新核对完整性的训练裁块。
  不能丢掉 ignore 字段后直接训练整张图。
- 蓝色桌布、空架、未穿戴手套、线缆、反光等优先从实际机位补充。
  “手部负样本”仍可能含其他目标；全类别训练必须补全其他类别标注。
- 公开数据须核对许可、标签本体、图像重复和分区来源。公开图片里的未标注目标
  不能直接充当该类别的负样本。只在能补足真实失效场景时加入。

## 导出与训练验收

每张图片保留源路径/摘要、原始尺寸、源组、人称及依据、分区、标注版本、
实例坐标、可见性、遮挡、审核状态、排除区域及草稿处理记录。
导出前检查框越界、零面积、未知类别、重复实例、漏标、未审核草稿、
分区泄漏、角色混入和源文件变更。仅标手部的图片不得直接进入全类别训练。

小样本从对应角色的已有权重启动候选实验，固定运行身份、数据摘要和参数；
按源组比较，单独检查密集目标漏检、重复框及真实困难背景上的误检。
训练指标只用于训练诊断；项目标注比较明确为内部证据。
生产替换仍需完整真实视频质量回执及适用的独立评测门禁。
