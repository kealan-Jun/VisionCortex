# 部署证据与历史边界

[返回文档导航](../README.md)

现场任务书、设备映射、运行日志和历史验收原文由部署方在私有证据存储中保存，
与对应源码提交、配置、输入及环境身份绑定，不作为客户安装包的通用操作指南。
公共文档不提供内部证据目录或历史原文的外部链接。

整理当前文件和交付导航不会删除既有 Git 提交中的内容。需要审查某个历史版本时，
在授权环境按其完整提交身份核对原始证据；历史运行结果不能替代当前部署验收。
本次整理不改写原始证据或 Git 历史。

当前验收使用[交付验收单](../VisionCortex-交付验收单模板.md)，
分别记录结构检查、实际模型调用、真实视频质量、浏览器交付和稳定运行的证据。
